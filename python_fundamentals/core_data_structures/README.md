# Python - Core Data Structures

This project practices Python's core data structures: lists, tuples, sets, and dictionaries.

## Files

| File | Description |
|---|---|
| `print_list_integer.py` | Prints list elements. |
| `element_at.py` | Retrieves an element. |
| `replace_in_list.py` | Replaces an element. |
| `print_matrix_integer.py` | Prints a matrix. |
| `add_tuple.py` | Adds tuple elements. |
| `common_elements.py` | Finds common set elements. |
| `update_dictionary.py` | Updates dictionary entries. |
| `best_score.py` | Finds the highest score. |

## Environment

- Python 3
- Ubuntu 20.04 LTS
- pycodestyle 2.7.x
