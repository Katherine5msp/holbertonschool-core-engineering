# Python - Functions & Modularity

This project introduces Python functions and modular programming.

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.x
- PEP8 compliance (pycodestyle 2.7.x)
- No external libraries
- No use of sys.argv
- All Python files must be executable and end with a newline.

## Tasks

### 0. islower
Implement a function that checks whether a character is a lowercase ASCII letter using ord().

### 1. Uppercase
Convert lowercase ASCII letters to uppercase using ord() and chr(), then print the result.

### 2. Print Last Digit
Print and return the last digit of an integer. The returned and printed digit must always be positive.
